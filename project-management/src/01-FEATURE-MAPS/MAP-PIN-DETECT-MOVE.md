## Destination

Every dependency surface this template ships is pinned exactly where the repository controls it,
the Rust workspace and the language runtimes excepted, scanned for advisories against those pins
(Grype for the shipped django prod image), and moved only deliberately: routine moves wait out a
7-day cooldown, and security moves happen at once through a named, reasoned exception. One
pin-detect-move rule in `code/docs/security/SUPPLY-CHAIN.md` states it. _(Confirmed as written by
Sam, this conversation, 16/10/2026 (Q15); narrowed by N-029 at Step 8a the same day, on Sam's yes
(Step 8a Q4).)_
