## 1. Scope

**What was built and reviewed:**

- **Settings** — `CSRF_COOKIE_HTTPONLY = True` in `base.py`, and `__Host-` session and CSRF names in `staging.py` and `production.py`.
- **The gate** — three `negative-space.sh` clauses (`csrf-cookie-httponly-absent`, `cookie-host-prefix-absent`, `cookie-scope-widened`) in `code/src/scripts/audits/_lib/negative-space-cookies.sh`, with their fixtures and self-test half.
- **Two migrations** — the unversioned `.copier/migrations/cookie-domain-conflict.sh`, which checks the project's state, and the pending cutover `.copier/migrations/host-only-cookies.sh`.
- **The preview repair** — in `code/src/scripts/development/template-update.sh`.
- **The test helper** — `code/src/scripts/tests/cookie-preview-fixture.sh`.
- **Docs** — the owner guide `code/docs/security/CRYPTO-AND-DATA.md` plus four deferring guides, and the edge clause in `how-to/src/SERVER-ARCHITECTURE/EDGE-REQUIREMENTS.md`.

There is no backend behaviour, API or frontend.

**What changed against the plan.** The scope matches the plan. These items depart from it, and each follows an implementation ruling of 16/11/2026 (Section 4):

- the cookie clauses sit in a sourced `_lib` file;
- a scanner twin ships inside the migration;
- the gate fails closed;
- the cutover entry ships with no version.

**Evidence, in order of preference:**

1. **Self-test case labels** from `cookie_self_test` and its sub-functions in
   `_lib/negative-space-cookies.sh`. These were exercised by `bash code/src/scripts/audits/negative-space.sh --self-test`, which exited 0 on 16/11/2026: "broken/ trips 14 clauses, clean/ trips none". It passed under gawk 5.4.1, mawk 1.3.4 and BusyBox 1.37 awk (`../../18-TESTS/AUTOMATED/US008-TEST-STATUS.md` Section 2). The harness reports only failures, so a label below is a case that ran and did not `st_fail`.
2. **Manual row IDs** from `../../18-TESTS/MANUAL/US008-MANUAL-TESTING.md`, walked 16/11/2026 at `43acdf5`: 50 Pass, 1 Fail, 3 Unmeasured. That guide's _Walk provenance_ records how each scratch copy was made:
   - one `git archive 43acdf5 | tar -x` per case under `mktemp -d`;
   - the fixture helper for generated projects;
   - a `git clone --no-hardlinks` with its own Compose project for the browser walk.

No pytest attributes to US008, by design. The gate is the invariant's one enforcer
(`code/docs/NEGATIVE-SPACE.md`), so `test-record.sh US008` correctly wrote 0 rows.
