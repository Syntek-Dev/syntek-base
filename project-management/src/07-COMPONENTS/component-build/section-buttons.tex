\brandsection{Buttons}

Buttons trigger actions. Use one primary action per section; lower-emphasis actions take the
secondary or ghost style. Every button keeps a minimum 44 x 44 px touch target.

\subhead{Variants}
\uibtn[primary]{Primary}\quad\uibtnoutline[primary]{Secondary}\quad\uibtnghost[primary]{Ghost}\quad\uibtn[accent]{Accent}\quad\uibtn[error]{Delete}\quad\uibtn[success]{Confirm}\par
\vspace{2mm}
{\small\color{muted}One primary action per section; secondary and ghost for lower-emphasis actions.}\par

\subhead{Sizes}
\uibtnsm[primary]{Small}\quad\uibtn[primary]{Default}\quad\uibtnlg[primary]{Large}\par

\subhead{States}
\uibtn[primary]{Default}\quad\uibtn[accent]{Hover}\quad\uibtn[muted]{Disabled}\par
\vspace{2mm}
{\small\color{muted}Icon-only buttons require an accessible label; disabled buttons drop to a muted fill.}\par
