\brandsection{Form Controls}

Form controls capture user input. Every field pairs a clear label with a bordered
control; state is communicated through border colour and supporting text rather than
colour alone, to satisfy WCAG 2.2 AA.

{\small\color{muted} Border colour signals state: neutral (default), accent (focus),
error (invalid). Never rely on colour as the sole cue.}

\vspace{4mm}
\subhead{Text Input}

{\small\textbf{Email}}\par
\vspace{1mm}
\uifieldbox[border]{\color{muted}you@example.com}

{\small\color{muted} Default resting state with a neutral border and placeholder text.}

\vspace{4mm}
\subhead{Focused Input}

{\small\textbf{Password}}\par
\vspace{1mm}
\uifieldbox[accent]{\color{muted}\textbullet\textbullet\textbullet\textbullet\textbullet}

{\small\color{muted} The accent border indicates keyboard focus; the value is masked.}

\vspace{4mm}
\subhead{Error Input}

{\small\textbf{Postcode}}\par
\vspace{1mm}
\uifieldbox[error]{\color{muted}invalid input}
\vspace{1mm}\par
{\small\color{error} Please enter a valid value.}

{\small\color{muted} An error border is always paired with a short, specific message.}

\vspace{4mm}
\subhead{Textarea}

{\small\textbf{Message}}\par
\vspace{1mm}
\uifieldbox[border]{\color{muted}Tell us a little about your project\\
and what you would like to achieve.}

{\small\color{muted} A multi-line control for longer free text; grows with content.}
