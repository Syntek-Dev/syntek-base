\brandsection{Alerts}

Alerts communicate a page-level status or system message to the reader. Each alert pairs a
coloured frame and title with a soft tinted background, so the message reads clearly without
competing with the surrounding content. Use them for feedback that applies to the whole page or
a completed action.

\vspace{2mm}

\subhead{Alert Variants}

\vspace{1mm}

\uialert{info}{infobg}{Information}{A short informational message for the reader.}

\vspace{2mm}

\uialert{success}{successbg}{Success}{Your changes have been saved successfully.}

\vspace{2mm}

\uialert{warning}{warningbg}{Caution}{This action may take a few minutes to complete.}

\vspace{2mm}

\uialert{error}{errorbg}{Error}{Something went wrong. Please try again.}

\vspace{3mm}

{\small\color{muted} Alerts are for page-level messages, not inline field validation. Reserve the
error variant for genuine failures, and pair the success variant with an action the reader has
just completed.}
