\brandsection{Badges \& Chips}

Badges and chips are compact, non-interactive (or lightly interactive) labels. Use \textbf{solid badges} to communicate fixed status, and \textbf{soft chips} for removable tags and filter selections.

\vspace{2mm}

\subhead{Status badges}

\uibadge[primary]{Project}\quad\uibadge[success]{Active}\quad\uibadge[warning]{Pending}\quad\uibadge[error]{Overdue}\quad\uibadge[info]{Info}

\vspace{2mm}
{\small\color{muted} Solid, white-text badges carry a single word of state. Map colour to meaning consistently: primary for neutral identity, success for healthy, warning for attention, error for blocking, info for advisory.}

\vspace{5mm}

\subhead{Chips / tags}

\uichip{Design}\quad\uichip{Frontend}\quad\uichip{GDPR}\quad\uichip{SEO}

\vspace{2mm}
{\small\color{muted} Soft outlined chips label removable tags and active filters. They read as lighter than badges, invite dismissal (an 'x' affordance in the live component), and can wrap freely across a filter bar.}

\vspace{5mm}

\subhead{When to use which}

\begin{itemize}[leftmargin=5mm,itemsep=1mm]
  \item \textbf{Badge} -- fixed, system-owned status the user cannot remove (Active, Overdue).
  \item \textbf{Chip} -- user-owned, removable selection: applied filters, assigned tags, chosen categories.
  \item Keep labels to one or two words; never sentence-length. Prefer a tooltip for detail.
\end{itemize}
