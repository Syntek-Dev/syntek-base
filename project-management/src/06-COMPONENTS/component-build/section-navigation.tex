\brandsection{Navigation}

Navigation components orient the user and move them between views. Each pattern
below is built only from brand tokens so top bars, tabs, and pagination stay
consistent across the marketing site and the admin portal.

\end{minipage}%
}}

{\small\color{muted} Light top bar on a panel surface --- ghost links for
low-emphasis destinations, one solid accent CTA on the right.}
