**Checked and not found:** a carrier spelling that yields a value while a second spelling hides
(every YAML key form counts toward `duplicated`); a suppression directive hiding a conflict marker
(raw-pattern second check); a `\u`-escaped or case-variant `currentContext` read differently from
Docker (both refused — cases 14b-saved-case, 14d-escaped-key, 14d-case-dup-cfg); a stale endpoint
surviving into a later call (outputs cleared at entry and on refusal; case `bind-unvalidated`); a
terminal escape in a hostile override or context name reaching the refusal (`printf %q`); the guard
reaching a daemon during resolution (recorder saw only `context ls` and `context inspect`, both with
selectors unset).

**Observations, not threats, routed to findings:** the default-context endpoint is the hard-coded
`unix:///var/run/docker.sock`, so a rootless-Docker host with no context selected binds the wrong
socket and the command fails — fail-closed, functional only; `restore.sh` validates its backup-file
argument (`:89-90`, exit 2) before the guard, so an operator with a mistyped path at `staging` sees
exit 2 rather than the refusal.
