# Required Sections — Vendor Assessment & Service Level Agreement

Required section lists for the vendor assessment report and the service level
agreement. Every document also carries the standard header, version history, ISO
alignment note, and disclaimer defined in [STANDARDS.md](STANDARDS.md).

---

## Vendor Assessment Report

1. Assessment header (vendor name, vendor type, risk level, assessment date, assessor)
2. Assessment Scope and Purpose
3. Company Information (about the vendor — registered name, address, key contacts)
4. Data Handling Practices
   - Categories of data accessed
   - Data storage locations and jurisdictions
   - Data retention and deletion practices
5. Security Controls
   - Access control and identity management
   - Encryption (at rest and in transit)
   - Network and perimeter security
   - Vulnerability management and patching
6. Incident Response Capabilities
   - Incident detection and notification procedures
   - Response timeframes and SLAs
7. Compliance Certifications (ISO 27001, SOC 2, Cyber Essentials, PCI DSS — as applicable)
8. Regulatory Compliance (UK GDPR, FCA, NHS DSP Toolkit — as applicable)
9. Audit and Penetration Testing Procedures
10. Sub-Processor and Supply Chain Management
11. Business Continuity and Disaster Recovery Capabilities
12. Risk Assessment Summary

    | Category | Score (1–5) | Risk Level | Notes |
    | -------- | ----------- | ---------- | ----- |

13. Recommendations
14. Sign-Off and Approval

---

## Service Level Agreement

1. Agreement header (service provider name, client name, service tier, effective date, agreement version)
2. Purpose and Scope
3. Service Description
   - Services included (precise description per service)
   - Services explicitly excluded
4. Performance Targets

   | Metric | Target | Measurement method | Reporting frequency |
   | ------ | ------ | ------------------ | ------------------- |

5. Incident Severity Classification and Response / Resolution Times

   | Severity      | Definition | Initial response time | Resolution target |
   | ------------- | ---------- | --------------------- | ----------------- |
   | Critical (P1) |            |                       |                   |
   | High (P2)     |            |                       |                   |
   | Medium (P3)   |            |                       |                   |
   | Low (P4)      |            |                       |                   |

6. Escalation Procedures (tiers, named contacts, contact methods, escalation timeframes)
7. Service Credits and Remedies

   | Target missed | Credit (% of monthly fee) | Credit cap |
   | ------------- | ------------------------- | ---------- |

8. Reporting and Service Reviews (frequency, format, attendees)
9. Planned Maintenance Windows (schedule, notice period, exclusion from SLA calculations)
10. Client Responsibilities (obligations the client must fulfil for SLA to apply)
11. Exclusions and Force Majeure
12. Review Schedule and Amendment Process
13. Approval and Sign-Off

> Currency is GBP (£); service credits are expressed as a percentage of the monthly fee.
