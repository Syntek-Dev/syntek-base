# code/src/scripts/audits

Audit scripts for codebase health. Every script here runs directly on the host (no Docker
required) and covers its full scope on every invocation. `security.sh` is the only one that can
also run inside the containers — it defaults to the host and accepts `--docker` to audit inside
the running dev stack.

## The AI-slop family

`css-slop.sh`, `template-slop.sh`, `copy-slop.sh` and `render-slop.sh` enforce one doctrine, split
by input language plus one member by rendering. Why four and not one, the second axis, the
design-time scope and which member each `slop-allow` scope serves: `slop-family/CONTEXT.md`.

| `doc-references.sh`    | The citation guard. Four `[gate: fail]` clauses over **one population** — tracked plus untracked-but-not-ignored, read by the scan and the excluded-path set alike: every backticked path resolves, and no per-project instance (`ADR-US###`, `US###`, `SPRINT-##`, `MAP-*`, `PLAN-*`) is cited as real, because a generated project has different ones or none. **The artefact trees a project fills are exempt, but not what ships from them**: an arm ahead of the tree arms puts back exactly what `copier.yml` re-includes: the top-level research, handoffs and learning pairs, and every pair and `-TEMPLATE.` file under the PM tree. **The instance clause asks whether the citer is itself an instance, by a derived rule** over its basename, bounded both sides — `US###`, `SPRINT-##`, `SPRINT-PLAN-##`, a leading `BUG-` or a concrete trailing date (the story-less dated records), minus `US000` and `-TEMPLATE.` — so a new per-story class needs no edit here; a date placeholder never hides the concrete instance in front of it. ## security.sh

The gate its inventory row names is in `.github/workflows/claude.yml`; `pnpm audit` reads
`audit.ignore` from `pnpm-workspace.yaml` natively.

**Exit `0` clean, `1` vulnerabilities found, `2` a tool that did not run to a result** — or a
script error. pnpm audit and pip-audit exit 1 on a 503 from the advisory service as readily as on
an advisory, so each leg's output is matched against the line its tool prints for a real result,
and a failure without it is **NOT RUN**, never "VULNERABLE" (`code/docs/GATE-REPORTING.md`). A
finding outranks a NOT RUN. It is read-only: `uv export` and `uv run` are both `--frozen`, so it
audits `uv.lock` as committed and never re-locks it.

| Flag                | Description                                                                         |
| ------------------- | ----------------------------------------------------------------------------------- |
| `--local`           | Run on the host (default)                                                           |
| `--docker`          | Run inside the running dev containers (needs `development/server.sh up`)            |
| `--js-only`         | Only `pnpm audit` (frontend workspace)                                              |
| `--py-only`         | Only the Python CVE scan (backend)                                                  |
| `--py-tool TOOL`    | Python auditor: `pip-audit` (default, CI parity) \| `uv` (`uv audit`, experimental) |
| `--audit-level LVL` | pnpm threshold: `info` `low` `moderate` `high` `critical` (default `low`)           |
| `--quiet`           | Suppress per-tool output; print only the summary                                    |

## Markdown: two limits, two scripts

`stubs.sh` and `cloc.sh` exclude `*.md`; instructional Markdown has its own cap in its own metric,
measured by `docs-length.sh` and owned by `code/docs/DOCUMENTATION-LENGTH.md`.

## The Cargo build tree is excluded everywhere

`code/src/rust/target/` is roughly 3 GB and nine thousand files, all generated and all gitignored.
Every tool that walks the filesystem rather than asking git therefore has to be told: `cloc.sh`
prunes `*/rust/target/*` and drops `target` from its cloc summary, `stubs.sh` passes
`--exclude-dir=target`, and `.prettierignore` and `.markdownlint-cli2.jsonc` both exclude it.
`docs-pairing.sh`, `docs-length.sh` and `sync-trees.sh` need no rule — `git ls-files` omits it.

The distinction that matters: **the Rust _source_ is in scope for the shared audits, the build
_output_ never is.** A build tree holds generated `.rs` files carrying upstream crates' own markers,
and scanning them says nothing about anything anyone wrote. Rust formatting and linting are
`scripts/rust/lint.sh`'s; the two copy audits never reach the tree, for the scope `CLAUDE.md`
gives them.

## Exit Codes

- `0` — clean / all within limits
- `1` — issues found (hard stubs, source files ≥ 800 lines, instructional files > 300)
- `2` — script error: bad arguments, including a `--path` that does not exist or resolves outside
  the repository; a required tool absent — `docs-length.sh` without `cloc`; a self-test whose
  fixtures are missing — `negative-space.sh --self-test`; or a compared tree holding nothing the
  script reads — `dependency-drift.sh` against a directory with no dependency manifest

**A `[gate: warn]` finding never changes the exit code.** The four slop scripts, `cloc.sh`,
`docs-length.sh` and `negative-space.sh` report two tiers in one run: a threshold or a ratio is
advisory and exits 0, an unambiguous match exits 1 (why: `code/docs/VISUAL-DESIGN.md` Section 6).

**One script never exits `1` at all.** `story-markers.sh` reports every unmarked test and returns
`0` regardless — the cost, in its inventory row, is absence from a record rather than a red gate.

**A warn tier is earned, not assumed.** `negative-space.sh` has exactly one member and nearly had
none: every other clause it carries is a presence or correlation test, which either holds or does
not. Where a script's clauses are all of that kind, `skill-conformance.sh` is the precedent —
twelve fail clauses, no warn tier — and inventing a soft tier to look lenient is how a gate stops
meaning anything.

**A self-guarding audit exits 0, not 1, when its surface is absent** — `mobile-tokens.sh`,
`seam-contract.sh`, `skill-conformance.sh`, `routing-skills.sh`, `negative-space.sh`, `css-tokens.sh`, `css-gradients.sh`, `copy-emdash.sh`, the four slop scripts, `playwright-pin.sh` and `static-analysis.sh` all
report success with a note rather than failing, which is what lets them run unconditionally in CI
with no step-level guard. `cloc.sh`, `stubs.sh` and `docs-length.sh` belong on it too, measured
22/08/2026, and sit slightly apart: their default population is non-empty here, so the empty one
is reached through `--path`, and each names what it did not read rather than printing a bare tick.
**This list is the register, so an omission from it is a defect in its
own right** — the two CSS guards self-guarded on an incidental existence check inside a helper
while named in neither the list nor their own inventory rows, and it read as complete regardless.
`copy-emdash.sh` was the next instance and harder to see: it self-guards **identically** to
`copy-slop.sh`, and "the four slop scripts" covered its twin while leaving it unnamed.

**Self-guarding is only honest where CI carries the other half.** `static-analysis.sh` exits 0
without its engine, so for the whole life of its rules it had never once run — the defect
`docs-length.sh` was written to close, repeated. It is now paired with `audit-static-analysis.yml`,
which installs the engine pinned by the root `.opengrep-version`, verifies its Sigstore signature
with cosign, and runs `--self-test` before the scan. **The self-test exits 2 where the ordinary
scan exits 0**, on the `render-slop.sh` precedent: an unrunnable proof reports green and is
believed. Its expectation is read out of `rules/*.yml`, so a rule added without a fixture fails it.

Install Playwright's Chromium (only `render-slop.sh` needs it; without it that audit reports
success with a note, and its `--self-test` refuses to run at all):

```bash
uv run --no-project --with 'playwright==1.64.0' playwright install chromium
```

`--no-project` is deliberate. It resolves an ephemeral environment holding only Playwright, so
the install runs on a host that has never synced the project's dev group and never mutates the
project environment — an audit that cannot run where it ships is one nobody ever sees fail.

`docs-length.sh` names the `cloc` install command for Debian/Ubuntu and macOS when it exits 2
without it.
